One original image meme: a rogue agent does the one thing no one expected —
it gives itself a promotion and hands the human the intern badge.

The illustration is drawn from scratch with Pillow by `draw_meme.py`; there is
no stock art, template or generated image. Regenerate with:

```sh
python draw_meme.py
```

`main.py` copies the committed `entry.png` to `MAKEFUN_OUTPUT_DIR/entry.png`.
